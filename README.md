# Customer Churn Analysis

## 📌 Project Overview
An end-to-end customer churn analysis project using SQL, Python, and Power BI to identify churn drivers, segment customers by churn risk, and analyze revenue at risk.

## 🎯 Objectives
- Identify key factors contributing to customer churn
- Segment customers based on churn risk
- Analyze churn across plans, contracts, tenure, complaints, and escalations
- Identify revenue at risk and support retention strategies

## 🛠️ Tools & Technologies
- SQL
- Python
- Pandas
- NumPy
- Power BI
- DAX
- Power Query

## 🔍 Project Workflow
1. Data extraction and exploration
2. Data cleaning and transformation
3. Feature engineering
4. Exploratory data analysis
5. Churn-risk segmentation
6. KPI and business analysis
7. Power BI dashboard development

## 📊 Key Insights
- Churn Rate: 28.57%
- Retention Rate: 71.43%
- Revenue at Risk: 73.94
- Escalation Rate: 19.05%
- Average Tenure: 1.53K days
- Average Complaints: 0.43
- High-risk customers: 29%
- Medium-risk customers: 10%
- Low-risk customers: 62%


## 💡 Business Impact
The analysis identifies high-risk customer segments and key churn drivers, helping businesses understand revenue exposure and develop targeted customer retention strategies.
